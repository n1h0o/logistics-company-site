# Контур Транзит — сайт логистической компании

Демонстрационный сайт для B2B-перевозок по России и СНГ. Название, заявки, маршруты и расчёты придуманы для этого продукта и помечены как демонстрационные. Форма не отправляет контактные данные.

## Возможности
- Адаптивный сайт услуг и географии.
- Поиск по трём явно учебным номерам отслеживания.
- Калькулятор ориентировочного диапазона на основе выбранного маршрута и массы.
- Навигация для мобильного и настольного вида.

## Запуск
```bash
npm install
npm run dev
```

## Проверки
```bash
npm run lint
npm run build
```
