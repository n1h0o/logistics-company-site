# Исследование дизайна

Дата: 2026-10-26. Запросы через Refero MCP вернули `NO_SUBSCRIPTION`; как предписано в `AGENTS.md`, исследован публичный каталог [styles.refero.design](https://styles.refero.design/), поиск по запросу `logistics freight transportation`.

## Найденные направления
- **Orderful** — «industrial command deck»: индустриальный интерфейс с визуальной точностью операционной панели.
- **Freitag** — швейцарский промышленный каталог: функциональная сетка и характерная типографика.
- **Dock** — светлая бумажная подложка с кобальтовым акцентом.
- **Uber** — монохромный транзитный киоск.

## Синтез
Основой выбран индустриальный command-deck Orderful: глубокий сине-графитовый фон и схема маршрута как центральный фирменный образ. Заимствованы ясная маркировка и редакционная сетка из Freitag, а ограниченная салатовая подсветка служит только сигналом маршрута и CTA. Это самостоятельная система, не копирующая сайт референса.

### Решения и отклонения
- Палитра: #112B3A, #18262C, #F3F5F2, #C8F078, #5DA7D8.
- Manrope для интерфейса, DM Mono для технических меток.
- Геометрический hero с SVG-схемой (схема помечена иллюстративной), плотные операционные статусы, много воздуха в информационных секциях.
- Анимация бегущей строки отключается при `prefers-reduced-motion`.
- Реальные карты, геоданные, цены и статистика не используются.
